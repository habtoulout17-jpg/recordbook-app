# BKTeach Recordbook app

Installable web app for Bilal's record book. It holds **no recordbook content**: after Google sign-in (teacher account only) and the access code, it reads the pages from the private repo `habtoulout17-jpg/recordbook` with a read-only key kept in Firestore (`teacherTools/github`, teacher-only).

Live at https://habtoulout17-jpg.github.io/recordbook-app/ — install from the browser menu ("Install app" / "Add to Home screen").

To update the recordbook itself, change the `recordbook` repo, not this one.
